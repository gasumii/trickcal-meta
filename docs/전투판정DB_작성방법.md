# 전투 판정 DB 작성 방법

사이트의 **전투 메커니즘 → 스킬 판정표**는 개인 엑셀(전투 판정 DB)에서 내보낸 데이터입니다. 이 문서는 그 데이터를 어떻게 만들고 검증했는지 적어 둔 것입니다.

## 현재 규모 (2026-10-24)

| 항목 | 값 |
|---|---|
| 사도 | 136명 |
| 효과 행 | 1,804줄 (효과 1개 = 1줄) |
| 아티팩트·스펠 | 86종 · 44종 (레벨당 증가로 Lv1~12 계산, 최대 Lv12) |
| 상태·용어 사전 | 123개 |
| 나무위키 Lv1/Lv10 대조 | 110명 완료 · 18명 대조 전(나무위키 미확인 표시) |

## 작성 절차 (사도 1명 기준)

1. **게임 화면 캡처** — 저학년·고학년·일반 공격(기본/강화)·어사이드2·어사이드3 화면. 게임 내 스킬 레벨이 10 미만이면 스킬 강화 화면의 Lv10 미리보기도 캡처
2. **원문 대조 3회** — 캡처의 스킬 설명을 엑셀에 옮긴 뒤 세 번 다시 대조 (원문은 엑셀에만 두고 사이트에는 싣지 않음)
3. **효과 단위로 분해** — 한 스킬 설명 안의 효과(피해·버프·디버프·CC·회복 등)를 한 줄씩 나누고 대상·발동 조건·수치·지속을 채움
4. **상태 이름 정리** — 존속·마탄·먹빛처럼 사도 고유 상태 이름은 상태·용어 사전에 정의하고, 표준 효과 유형(공격력 증가, 기절 등)으로 묶음
5. **나무위키 대조** — Lv1·Lv10 수치를 옮겨 적고 게임 값과 비교. 어긋나면 게임 화면을 기준으로 삼고 차이를 기록
6. **모호한 점 기록** — 확률 미표기, 대상 생략, 합계/1회 기준 불명확, 표기 불일치 등을 '검증 포인트'에 남김
7. **같은 패턴 전체 검색** — 새로 찾은 표기 문제가 다른 사도에게도 있는지 DB 전체를 다시 확인

## 확실도 기준

| 확실도 | 뜻 |
|---|---|
| 설명 기준 | 게임 스킬 설명만 보고 정리 |
| 추정 | 설명이 모호해 해석으로 정리 (근거는 검증 포인트에) |
| 확인됨 | 게임 화면(스킬 강화 미리보기 등)이나 직접 실험으로 확인 |

## 대조하면서 확인된 것

- **스킬 성장이 선형이 아닌 경우 10건** — 나무위키 Lv1·Lv10 사이를 같은 폭으로 나누면 게임의 중간 레벨 값과 맞지 않았고, Lv10 미리보기로 확인하니 후반 레벨 증가폭이 더 컸음. 그래서 계산용 수치는 모두 게임 Lv10 미리보기 기준으로 통일
- **문서 쪽 오기 1건** — 게임은 선형인데 나무위키 Lv10 값이 다르게 적힌 경우(아르코 고학년)
- 표기·해석 문제는 각 행의 '검증 포인트'에 정리 (예: 발동 확률 미표기, '마지막 타격' 수치 기준, 콜론 띄어쓰기 불일치)

## 공개 원칙

- 게임 스킬 원문은 싣지 않고, 정리한 대상·조건·수치만 공개
- 유저 실측 계산법·커뮤니티 자료를 쓴 부분은 출처를 함께 표기
- 처음 이해와 다르게 확인된 내용은 지우지 않고 **정정 기록**에 남김
