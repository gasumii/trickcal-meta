# 트릭컬 리바이브 PvE 상위권 덱 리포트

게임 내 PvE 순위 화면의 상위권 덱을 직접 기록하고, 사도 채용률·티어·메타를 정리한 페이지입니다.

## 파일 구성
- `index.html` — 페이지 (수정할 필요 없음)
- `data/decks.csv` — 순위별 덱 (순위, 단계, 보스, 사도1~9)
- `data/sado.csv` — 사도 목록 (사도명, 속성, 코멘트)
- `data/info.csv` — 조사 정보, 한줄요약, 메타 코멘트

## 업데이트 방법
1. 엑셀에서 데이터 수정
2. 해당 시트를 "CSV UTF-8 (쉼표로 분리)" 형식으로 저장
3. `data` 폴더의 같은 이름 파일을 덮어쓰기 → GitHub에 커밋

티어표·차트·데이터 점검은 CSV를 읽어 자동으로 다시 그려집니다.
